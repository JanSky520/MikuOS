# 8086 汇编基础
## 寄存器介绍
|常用寄存器|主要用途|
|:-:|:-:|
|AX| 乘除运算、中断调用|
|BX|内存寻址|
|CX|循环次数、移位位数、串操作计数|
|DX|端口地址、乘除运算高位|

|寄存器组合|功能|
|:-:|:-:|
|CS:IP|指向当前正在执行的指令|
|SS:SP|指向栈顶|
|SS:BP|作为配合 SP 使用|
|DS:SI|指向源数据段|
|ES:DI|指向目标数据段|

|乘法|使用的寄存器|
|:-:|:-:|
|8 位|被乘数放入 AL，结果放入 AX|
|16 位|被乘数放入 AX，结果放入 DX:AX|

|除法|使用的寄存器|
|:-:|:-:|
|8 位|被除数放入 AX，商放入 AL，余数放入 AH|
|16 位|被除数放入 DX:AX，商放入 AX，余数放入DX|

## 汇编指令
```nasm
    var dw 0x1234         ;; 定义变量
    arr resb 100          ;; 100 字节数组未初始化
    ptr dw var            ;; 把 var 的地址放入 tex 中

    lea ax, [bx+si+10]    ;; 计算内存地址，并将地址值存入寄存器，而不是访问该地址的内容
    mov ax, ds:[10h]      ;; 读取 ds:[10h] 里的数据放到 ax
    mov ax, var           ;; ax = var 的地址
    mov ax, [var]         ;; ax = var 的内容
    mov word [var], 2     ;; 为 var 重新赋值
```

# 实模式到保护模式
## 计算机的启动过程
1. 计算机开机后，CS:IP 寄存器被强制初始化为 0xF000:0xFFF0，CPU 会自动跳转到地址 0xFFFF0 的 BIOS 入口处执行 `jmp far f000:e05b` 代码
2. BIOS 检测内存、显卡等外设信息，当检测通过，并初始化好硬件后，开始在内存中 0x000 ~ 0x3FF 处建立中断向量表 IVT 并填写中断例程
3. 根据启动顺序扫描硬盘等设备，读取第一个扇区，最后两个字节是 0xAA55 就把这个扇区加载到 0x7C00
4. 通过硬盘操作，把第二个扇区设置为 loader，从 mbr 跳转到 loader，进行内存的检测、打开 A20、加载 GDT、将 CR0 寄存器的 PE 值 1 ，开启保护模式
5. 准备好页目录表及页表，将页表地址写入控制寄存器 CR3 再将 CR0 寄存器的 PG 置为 1 开启分页，进入内核
## 内存区域分配
+ 从低地址看 0x00000 ~ 0x9FFFF 属于 DRAM 内存条，其他地址则属于 BIOS ROM 或者显存等
## 硬盘操作
+ 0X1F0：16位端口，用于读写数据
+ 0X1F1：检测前一个指令的错误（基本用不到）
+ 0X1F2：读写扇区的数量，最大256
+ 0X1F3：起始扇区的 0~7 位
+ 0X1F4：起始扇区的 8~15 位
+ 0X1F5：起始扇区的 16~23 位
+ 0X1F6：device 寄存器
  - 3：起始扇区的 24~27 位
  - 4：0 表示主盘，1 表示从盘
  - 6：0 表示 CHS，1 表示 LBA
  - 5 与 7：固定是 1
+ 0X1F7：out 操作
  - 0XEC：识别硬盘
  - 0X20：读硬盘
  - 0X30：写硬盘
+ 0X1F7：in 操作
  - 0：ERR，此位为 1 表示有错误发生
  - 3：DRQ，此位为 1 表示硬盘已经准备好数据，随时可以输出
  - 6：DRDY，此位为 1 表示设备就绪，等待指令
  - 7：BSY，此位为 1 表示硬盘正忙，勿扰
